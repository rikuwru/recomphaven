      What counts as a recomp

      A static recompilation translates a game's original machine code (MIPS on the N64 and PlayStation, PowerPC on the Xbox 360 and GameCube) into C or C++ ahead of time, then compiles it into a native program. No emulator runs while you play, which is how these ports add widescreen, high frame rates and mod support.

      Decompilations and disassemblies, where people rebuild a game's source code by hand, are listed too, along with the native ports compiled from them, with Decompilation or Disassembly as their toolchain. Emulators and compatibility layers, which run a game's original code without translating or rebuilding it, aren't listed. The one exception is P.T., a hand-made reimplementation of the PS4 teaser, labelled Reimplementation.
